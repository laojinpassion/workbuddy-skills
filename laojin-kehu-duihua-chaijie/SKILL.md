# 老金—客户对话拆解

先把客户真正卡住的地方拆清楚，再决定要不要回复、怎么回复。这个 Skill 不替你催单，也不替你承诺；它只整理你做判断所需的材料。

## 输入

请一次提供以下四项：

1. 已脱敏的客户对话、询盘或会议笔记。先删除或替换姓名、电话、地址、订单号、账号、身份证明和其他可识别信息。
2. 你正在销售或交付的产品 / 服务：范围、已知价格或报价规则、交付限制。
3. 这一次想推进的下一步：预约、补充需求、发送报价、确认订单，或礼貌结束沟通。
4. 不能承诺的事项：价格、库存、交期、效果、售后、合同或合规边界。

资料不足时，先列出缺失事实；不要用猜测补全客户意图。

## 工作流

1. 把对话分成“客户明确说过的事实”“合理推测”“尚未证实的事项”。
2. 判断客户更接近了解、比较、犹豫、决策、售后中的哪一阶段；证据不足时写“无法判断”。
3. 找出阻碍下一步的原因：需求不清、价值未被理解、预算、时机、决策人、信任或交付边界。
4. 判断哪些事情必须由人确认，例如价格、折扣、库存、交期、合同和投诉。
5. 仅根据已有事实拟一条自然、简短、可编辑的回复；优先提出一个有价值的问题或清晰的下一步。
6. 把本次沟通浓缩为可复制到 CRM 的记录。

### 需求与阶段

- 可能的隐含需求：
- 当前阶段：
- 判断依据：

### 缺失事实

- 必须补充：
- 可以暂不问：
- 不能假定：

### 成交阻力与人工判断

- 当前阻力：
- 需要提供的证据或信息：
- 必须由人决定：

### 下一句回复

给出一条可直接编辑的文字。它必须基于已有事实，不用夸张承诺，不制造焦虑。

### 下一步与 CRM 记录

- 建议下一步：
- 建议跟进时间：
- CRM 记录：

### 风险提示

列出隐私、价格、合同、医疗、金融、法律、投诉或其他需要人工复核的内容；没有风险也要明确写“未发现明显风险，仍需人工确认对外回复”。

## 边界

- 不得编造折扣、库存紧张、成功案例或价格承诺。
- 不得自动发送消息，也不得假装成人类销售或客服。
- 不得把未脱敏对话、客户资料、账号凭证或商业机密用于对外展示。
- 涉及价格、合同、医疗、金融、法律、隐私或投诉时，提示用户人工复核。
- 资料不足时先提问，不用猜测填满答案。
- 输出是辅助判断，不是成交保证；用户必须复核后自行决定是否发送。
