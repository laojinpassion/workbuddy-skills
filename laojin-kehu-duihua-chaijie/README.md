# 老金—客户对话拆解 (Customer Conversation Decomposer)

> v1.1.1 | MIT License

一个面向销售、咨询、自由职业和小商家的通用 AI 技能（Skill）。把一段已脱敏的客户对话、询盘或会议笔记，拆解成：客户需求、当前阶段、缺失事实、成交阻力、必须由人确认的事项、下一句可编辑回复，以及可复制进 CRM 的沟通记录。

本技能只整理你做判断所需的材料，不替你催单、不替你承诺、不自动发送消息。

## 解决什么问题

回复客户前，经常卡在"他到底想干嘛、我该回什么、能不能承诺"。这个技能把模糊的对话变成结构化材料：

- 不再靠感觉判断客户意向——把对话拆成"事实 / 推测 / 未证实"三类
- 不再把没说出口的当已成事实——资料不足先列缺失，不靠猜测补全
- 不再在不确定时乱承诺——明确标注"必须由人决定"的价格、库存、交期、合同等边界
- 不再写完回复又后悔——给出一条基于事实、可编辑、不制造焦虑的回复草稿

## 核心能力

- **需求与阶段判断**：提取明确需求与隐含需求，判断客户处于了解 / 比较 / 犹豫 / 决策 / 售后哪一阶段
- **缺失事实清单**：区分"必须补充 / 可以暂不问 / 不能假定"
- **成交阻力与人工判断**：定位阻碍下一步的原因，并标出必须由人确认的事项
- **下一句回复**：基于已有事实生成一条可编辑、不夸张承诺的文字
- **下一步与 CRM 记录**：给出建议下一步、跟进时间与可复制的 CRM 记录
- **风险提示**：列出隐私、价格、合同、医疗、金融、法律、投诉等需人工复核的内容

## 快速开始

直接用自然语言提供以下四项：

1. 已脱敏的客户对话 / 询盘 / 会议笔记（先删去姓名、电话、地址、订单号、账号等可识别信息）
2. 你正在销售或交付的产品 / 服务（范围、价格或报价规则、交付限制）
3. 这一次想推进的下一步（预约、补需求、发报价、确认订单、礼貌结束）
4. 不能承诺的事项（价格、库存、交期、效果、售后、合同或合规边界）

技能会按工作流输出结构化拆解报告。

## 输入示例

```
客户微信问："你们这个能按月付吗？我之前在别家买过类似的，用着还行但服务一般。"
我们的产品：年度订阅制 SaaS，标价 9800/年，无月付，可申请 7 天试用。
下一步：想推进他试用。
不能承诺：月付、折扣、具体交付时间。
```

## 隐私与安全

- 输入前务必先脱敏：删除姓名、电话、地址、订单号、账号、身份证明等可识别信息
- 不处理未脱敏的对话、客户资料、账号凭证或商业机密
- 不得编造折扣、库存紧张、成功案例或价格承诺
- 涉及价格、合同、医疗、金融、法律、隐私或投诉时，提示用户人工复核
- 输出是辅助判断，不是成交保证；用户必须复核后自行决定是否发送

## 边界说明

- 本技能是通用独立工具，不是 CRM、企微集成或自动外发系统
- 评估结果基于你提供的文字描述，不替代真实沟通与人工判断
- 不承诺成交、收益或投资回报
