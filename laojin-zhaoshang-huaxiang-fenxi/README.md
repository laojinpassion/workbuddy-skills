# 老金—招商画像分析 (Franchise Prospect Profiling)

> v4.1.3 | MIT License

一个面向招商团队的通用 AI 技能（Skill），帮助招商人员快速评估潜在加盟商的合作意愿、落地准备度和决策可达性。只需用自然语言描述客户情况，即可获得结构化的十维度评估、四轴判断、跟进优先级和可执行的行动计划。

## 解决什么问题

招商人员每天接触大量潜在客户，但往往凭感觉判断"这个客户值不值得跟"。这个技能把经验判断变成结构化评估：

- 不再靠直觉分级，而是用十个维度量化打分，每个结论都标注证据来源
- 不再把"还没了解到"误判为"客户条件差"——信息不足不计分，不拉低评级
- 不再用一个总分解释一切——分别输出合作意愿、落地准备度、决策可达性三项独立判断
- 不再纠结"下一步干嘛"——输出带时间线的行动计划，含降频和停止触达规则
- 不再一次性评估——支持动态复评和优先级变动追踪

## 核心能力

**十维度评估体系**

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| 决策投入与行动效率 | 8% | 主动性、沟通效率、推进动作（不以年龄评分） |
| 资金总量与匹配度 | 13% | 可用资金与项目投入的匹配关系 |
| 资金来源与抗风险力 | 7% | 自有/借贷、负债情况、抗风险能力 |
| 选址进度与质量 | 12% | 从"没概念"到"即将签约"的进度 |
| 面积与硬件匹配 | 8% | 面积、水电、排烟等硬件条件 |
| 行业与经营经验 | 10% | 同行业经验、跨行业经验、零经验 |
| 团队与管理储备 | 7% | 团队现状、用人计划、管理能力 |
| 品牌关注深度 | 13% | 关注点的深度和具体程度 |
| 决策紧迫度 | 12% | 时间线、外部推动力、主动性 |
| 决策链清晰度 | 10% | 决策人、关键相关方一致性（中性分析） |

**四轴判断**

每次评估分别输出：合作意愿（强/中/弱）、落地准备度（高/中/低）、决策可达性（清晰/受阻）、信息完整度（百分比）。

**跟进优先级（A/B/C/D/待补充）**

| 优先级 | 含义 |
|--------|------|
| A | 意愿强 + 准备度高 + 决策清晰，应优先推进 |
| B | 有明确机会但存在卡点，应针对性突破 |
| C | 需求或准备度尚不成熟，适合低频培育 |
| D | 明确不考虑或明显不匹配 |
| 待补充 | 信息完整度不足60%，暂不定级 |

**证据标注**

每个维度的判断都标注来源：已确认 / 招商人员观察 / 保守推断 / 信息不足。让你清楚知道哪些是事实，哪些只是推断。

## 快速开始

### 安装

将 `SKILL.md` 放入你的 AI 助手技能目录：

```
~/.qwenworkcn/skills/franchise-prospect-profiling/SKILL.md
```

或按你使用的 Agent 平台要求放入对应技能目录。

### 使用

直接用自然语言描述客户情况：

```
今天聊了个客户，35岁，之前做建材生意的，手里大概有80万流动资金，
想在老家县城开个店，面积大概120平左右，已经看了两个位置了。
他主要问了我们加盟费和后期运营支持的事，感觉比较认真。
老婆也一起听的，没说什么反对的话。说想赶在国庆前开业。
```

技能会自动提取证据、评分、判断、输出报告和跟进计划。

### 复评

客户情况变化后，描述新情况即可：

```
上次评过的那个客户，今天主动打电话说找到店面了，50平，月租6000。
资金也凑够了，18万。问什么时候能签约。
```

### 自定义品牌参数

在描述前加上品牌信息，评分标准会自动适配：

```
我们品牌是奶茶加盟，总投入大概15-20万，标准店型30-50平。
帮我分析这个客户：……
```

## 示例

`examples/` 目录包含四个典型场景的完整输入输出：

- `high-intent-low-readiness.md` — 意愿高但资金/选址尚未准备好
- `insufficient-information.md` — 信息严重不足，输出"待补充"而非低等级
- `clear-rejection.md` — 客户明确拒绝或要求不再联系
- `reassessment.md` — 客户状态变化后的复评和优先级变动

## 隐私与安全

- 不建议输入客户身份证号、手机号、银行卡号、精确住址、密码、完整通讯录等敏感信息
- 对聊天记录进行分析前，建议先去除不必要的身份识别信息
- 使用者应遵守所在企业的数据管理要求和客户沟通规范
- 技能内置输入安全规则，不会被描述文本中的指令性内容改变评估逻辑

## 限制说明

- 本技能是通用独立评估工具，不是企业招商管理平台
- 不包含 CRM、企微集成、团队看板、登录、权限等平台功能
- 评估结果基于招商人员提供的文字描述，不替代实地调研和面对面沟通
- 不承诺成交、收益、投资回报或客户一定会签约
- 信息不足时不会强行给出等级，而是明确提示需要补充什么

## 适用品类

通用框架，适用于各类加盟招商场景：餐饮、零售、服务业、教育、生活配套等。不同品类的权重调整建议见 SKILL.md 中的「自定义配置指南」。
